
# ♟️ Chess Game

## 📌 Présentation

Chess Game est un projet personnel en cours de développement, réalisé en Python avec la bibliothèque Pygame.

L'objectif est de créer un jeu d'échecs avec une interface graphique permettant d'afficher l'échiquier, de représenter les pièces et d'interagir avec elles.

## 🛠️ Technologies utilisées

- Python
- Pygame

## 🚧 État du développement

Le projet est actuellement en développement. L'interface graphique et les interactions avec les pièces sont en cours de réalisation. Certaines règles du jeu restent à implémenter.

## 🎯 Objectif du projet

Approfondir mes connaissances en Python, en programmation orientée objet et en développement d'interfaces graphiques.
